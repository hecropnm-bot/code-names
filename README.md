# كود نيمز - لعبة عربية متعددة اللاعبين

تطبيق لعبة كود نيمز عربي كامل مع غرف مباشرة، فرق، قائد فريق، تلميحات، لوحة 5x5، وفوز أو خسارة عند كشف القاتل.

يدعم التطبيق طورين:

- غرفة أونلاين: كل لاعب يدخل من جهازه، وكل فريق يحتاج قائدًا ولاعب تخمين قبل البداية.
- لمة: فريقان في نفس المكان على جهاز واحد، وصاحب الغرفة يدير التلميح والكشف للفريقين.

## التشغيل المحلي

```bash
npm install
npm start
```

ثم افتح:

```text
http://localhost:3000
```

## النشر

هذا المشروع يحتاج استضافة Node.js تدعم WebSocket مثل Render أو Railway أو Fly.io.

ملاحظة مهمة:

- Vercel مناسب لعرض الواجهة وطور لمة المحلي من جهاز واحد.
- غرف الأونلاين الحقيقية تحتاج Render أو Railway لأن Socket.IO يحتاج خادم Node دائم.
- تمت إضافة `render.yaml` لتسهيل نشر نسخة الأونلاين، وتمت إضافة PWA حتى يمكن تثبيت اللعبة على الهاتف.

إعدادات النشر:

- Build command: `npm install`
- Start command: `npm start`
- Node version: 18 أو أحدث

## ملاحظات

- كل الغرف تعمل مباشرة عبر Socket.IO.
- القائد فقط يرى خريطة البطاقات السرية.
- اللاعبون لا تصلهم الأدوار السرية إلا بعد كشف البطاقة.
- لا يمكن كشف بطاقة قبل التلميح، وعدد التخمينات مقيد برقم التلميح + تخمين إضافي واحد.
- توجد مؤثرات صوتية خفيفة للضغط، النجاح، الخطأ، الكشف، والفوز.
- بنك الكلمات يحتوي على أكثر من 500 كلمة عربية.
- طور لمة مصمم ليعمل من هاتف واحد: وضع القائد يعرض الخريطة، ووضع التخمين يخفيها قبل تسليم الهاتف.
- الواجهة عربية بالكامل ومناسبة للهاتف.
